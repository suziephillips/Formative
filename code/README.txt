# This project explores the Physical Activity Monitoring Data and the Body Measures Data from the 2005-2006 NHANES cycle database.

# The Physical Activity Monitoring Data consists of 7456 individual text files, each containing information on the following:
#reliability of the data
#calibration of the device
#day, hour and minute when the data was captured
#observation number
#device step count

#7324 files have 10082 rows, 132 files contain files with a different number of rows

#The Body Measures Data consited of 1 csv file, containing data on 9950 participants. The dataset contains information on the following:
#participant identification number
#data completeness status
#participant weight
#participant weight commentary (in categories)
#participant Recumbent length
#participant Recumbent length commentary (in categories)
#pt head circumfrence
#pt head circumfrence commentry (in categories)
#pt standing height (in cm)
#pt standing height commentary (categorical)
#pt BMI (kg/m^2)
#upper leg length (cm)
#this continues for leg length, calf, arm length, arm circumfrence, waist circumfrence, thigh circumfrence, triceps, ...
